# pos_cashmatic — POS Cashmatic Cash Machines

Depends on: point_of_sale.

## `pos.payment.method` (extends)

- `cashmatic_ip` Char “Cashmatic IP”
- `cashmatic_username` Char “Cashmatic Username”
- `cashmatic_password` Char “Cashmatic Password”
- `cashmatic_use_lna` Boolean “Cashmatic Local Network Access”

Extension points: `_get_payment_method_type`
