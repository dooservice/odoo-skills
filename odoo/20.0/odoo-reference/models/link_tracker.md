# link_tracker — Link Tracker

Depends on: utm, mail.

## `link.tracker` (defines)

Link Tracker

Inherits: `utm.mixin`

- `url` Char “Target URL” (required)
- `absolute_url` Char “Absolute URL” (compute=_compute_absolute_url)
- `short_url` Char “Tracked URL” (compute=_compute_short_url)
- `redirected_url` Char “Redirected URL” (compute=_compute_redirected_url)
- `short_url_host` Char “Host of the short URL” (compute=_compute_short_url_host)
- `title` Char “Page Title” (store)
- `label` Char “Button label”
- `link_code_ids` One2many → `link.tracker.code` “Codes”
- `code` Char “Short URL code” (compute=_compute_code)
- `link_click_ids` One2many → `link.tracker.click` “Clicks”
- `count` Integer “Number of Clicks” (store, compute=_compute_count)
- `campaign_id` Many2one
- `medium_id` Many2one
- `source_id` Many2one

Public methods: `action_download_qrcode`, `action_view_statistics`, `action_visit_page`, `convert_links`, `create`, `get_url_from_code`, `recent_links`, `search_or_create`

Extension points: `_check_unicity`, `_get_title_from_url`

## `link.tracker.code` (defines)

Link Tracker Code

- `code` Char “Short URL Code” (required, store)
- `link_id` Many2one → `link.tracker` (required, index)

Extension points: `_get_random_code_strings`

## `link.tracker.click` (defines)

Link Tracker Click

- `campaign_id` Many2one → `utm.campaign` (store, related=link_id.campaign_id)
- `link_id` Many2one → `link.tracker` (required, index)
- `ip` Char “Internet Protocol”
- `country_id` Many2one → `res.country`

Public methods: `add_click`

Extension points: `_prepare_click_values_from_route`
