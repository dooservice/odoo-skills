# pos_cashdro — POS Cashdro Cash Machines

Depends on: point_of_sale.

## `pos.payment.method` (extends)

- `cashdro_ip` Char “Cashdro IP”
- `cashdro_username` Char “Cashdro Username”
- `cashdro_password` Char “Cashdro Password”
- `cashdro_use_lna` Boolean “Cashdro Local Network Access”

Extension points: `_get_cash_machine_selection`
